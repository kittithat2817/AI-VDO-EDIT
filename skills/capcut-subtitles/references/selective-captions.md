# ซับเลือกเน้นเมื่อผู้ใช้หรือโปรไฟล์ระบุ

แยก transcript เต็มสำหรับวิเคราะห์ออกจาก display cues ที่เลือกให้ขึ้นจอ รับ mode, target_words, max_words, terms, keyword policy และข้อรักษาความหมายจากโปรไฟล์ที่ผู้ใช้เลือก ไม่ทำความชอบของคลิปหนึ่งเป็นค่าเริ่มต้นของทุกงาน

เลือก cue ตามสารที่ช่วยเข้าใจหรือควรจำ ข้ามคำเกริ่น filler และคำซ้ำที่ไม่เพิ่มสาร Keyword เป็นศัพท์สำคัญหนึ่งคำ/ชื่อเฉพาะเมื่อสมควรเน้น ไม่เปลี่ยนเป็น karaoke ทุกคำเพื่อหลบเพดานความยาว หลีกเลี่ยง main caption กับ keyword ที่ขึ้นข้อความเดียวกันทับช่วงเวลาโดยไร้หน้าที่เพิ่ม

นับคำไทยด้วยการแบ่งคำและพจนานุกรมชื่อเฉพาะ/ตัวเลขช่วงที่มีเหตุผล ตรวจหน่วยคำและพื้นที่ภาพจริง ไม่ใช้ช่องว่าง จำนวน ASR token หรือหั่นอักขระเป็นคำ ระบุ purpose, source range, edited start/end และ role (main/keyword/sop) ใน cue list

รักษาคำว่าไม่/อาจ/โอกาส/น้อยลงและเงื่อนไขที่เปลี่ยนความหมาย เพดานคำของซับเล่าเรื่องไม่ครอบหมายเหตุ SOP ที่ต้องครบ แยกศัพท์แบรนด์กับวลีที่ผู้ใช้กำหนดคำสะกด เช่นสโลแกน เพื่อไม่ให้ normalization เปลี่ยนคำ

ตรวจเวลาบน draft ล่าสุดหลังตัดแล้ว งานซับอย่างเดียวคงภาพ/เสียงตามเดิม ใช้ plain text ตามขอบเขตสกิลนี้ การตกแต่ง preset/animation ที่ผู้ใช้ร้องขอในงานตัดต่อเต็มให้ capcut-script-edit ใช้ทรัพยากรที่ตรวจได้ตามบรีฟ แยกจากการเลือกข้อความ


เมื่อผู้ใช้/profile เลือก max_lines=1 และ shared caption anchor ให้ทั้ง main และ keyword หนึ่งบรรทัดในตำแหน่งอ้างอิงเดียวกัน ตรวจความกว้างกับฟอนต์/scale/spacing/กล่องโดย Thai shaping และวัดใหม่เมื่อข้อความเปลี่ยน นับคำผ่านไม่ได้แปลว่ากล่องพอดี หากล้นให้เลือกสารกระชับหรือแบ่งตามความหมายก่อนลดขนาดอย่างอ่านง่าย ไม่ crop หรือบีบตัวอักษร เก็บผล layout.text/method/width/available_width/estimated_lines และ binding ของ native ตามสัญญา planner; ข้อความ SOP อยู่นอกเพดานและคงครบ งานซับอย่างเดียวคงภาพ/เสียงเดิม
