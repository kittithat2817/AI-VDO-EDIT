# โปรไฟล์ซับธรรมดาที่ใช้ซ้ำได้

อ่านเมื่อขอทำซับแบบเดิมในคลิปใหม่ หรือเก็บแนวทางสำหรับซีรีส์ ข้อกำหนดคือ file-only และไม่เพิ่ม template/animation

## แยกแนวทางออกจากข้อมูลคลิป

- โปรไฟล์เก็บชื่อ/version และขอบเขต หลักการถอดคำพูด อภิธานศัพท์ที่ใช้ข้ามงาน การแบ่งวลี เพดานคำต่อบรรทัดแยกจากเพดานคำต่อ cue จำนวนบรรทัด เวลาอ่าน และรูปแบบตัวอักษรที่ผู้ใช้ขอให้ใช้ซ้ำ ตรวจใหม่เมื่อภาษาหรือสัดส่วนภาพเปลี่ยน
- ข้อมูลแต่ละงานเก็บ draft path/revision/schema/timebase/FPS, ช่วง In–Out, ค่าจาก Subtitle Preview, source audio, transcript, cue text/timing, track/material IDs, ข้อสงสัย และผลตรวจ ย้ายเฉพาะค่าการจัดซับเข้าโปรไฟล์เมื่อผู้ใช้ขอให้ใช้ซ้ำ
- ไม่ทำคำสั่งย่อเป็น keyword ในคลิปหนึ่งให้เป็นค่าเริ่มต้นทุกงาน ซับครบตามคำพูดยังคงเป็นค่าเริ่มต้น เว้นแต่ผู้ใช้ระบุเปลี่ยนขอบเขต

## วิธีใช้ซ้ำ

1. หาโปรไฟล์ที่ผู้ใช้ระบุในขอบเขตงาน หากไม่มีให้ใช้บรีฟปัจจุบัน ถ้าต้องอ้างคลิปก่อนและยังไม่ทราบว่าอันไหนให้ถาม
2. เก็บโปรไฟล์สั้นเมื่อจำเป็นในโฟลเดอร์ workflow ของงาน เช่น work/workflows/<profile-name>.md ส่งพาธจริงสำหรับครั้งหน้า แยก job state และไม่แก้ SKILL.md ตามสไตล์เฉพาะคลิป
3. ตรวจ draft และ native plain text/caption structure ของงานใหม่ ไม่มีการนำ preset/animation ของโปรไฟล์เก่าเข้ามา ตรวจฟอนต์/ภาษา/ขนาดภาพก่อนใช้รูปแบบพื้นฐานต่อ
4. ฟัง/ถอดข้อความและจับเวลาใหม่กับไทม์ไลน์ล่าสุด คำว่าใช้รูปแบบเดิมไม่อนุญาตให้คัด cue เก่าหรือเลื่อนเวลาทั้งชุดเป็นคลิปใหม่
5. เมื่อ resume คลิปเดิม เทียบ fingerprint/revision และคำนวณส่วนที่เปลี่ยนใหม่ ตรวจภาพ/เสียงไม่ถูกแก้จากการทำซับ และระบุข้อจำกัดการตรวจภาพจริงเสมอ
