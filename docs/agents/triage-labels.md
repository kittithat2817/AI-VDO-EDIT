# Triage Labels

| บทบาท | สถานะใน tracker | ความหมาย |
| --- | --- | --- |
| needs-triage | needs-triage | รอผู้ดูแลประเมิน |
| needs-info | needs-info | รอข้อมูลเพิ่มเติมจากผู้แจ้ง |
| ready-for-agent | ready-for-agent | ข้อกำหนดครบ พร้อมให้เอเจนต์ทำงาน |
| ready-for-human | ready-for-human | ต้องให้มนุษย์ดำเนินการ |
| wontfix | wontfix | จะไม่ดำเนินการ |

เมื่อ skill อ้างถึงบทบาท ให้ใช้ชื่อสถานะตามตารางนี้ในบรรทัด `Status:`

สามารถแก้คอลัมน์สถานะใน tracker เพื่อเปลี่ยนชื่อที่ใช้งานได้ภายหลัง
